# Internet Cable TV Offers

Modern, SEO + GEO optimised internet & cable TV comparison website built with Next.js 16, Tailwind CSS v4 and Motion.

- Home, Internet Providers hub, 7 internet-type pages, 9 provider landing pages
- FAQs, About, Contact, Privacy Policy, Terms & Conditions, Disclaimer
- Structured data (Organization, WebSite, BreadcrumbList, FAQPage, ItemList, Service), sitemap, robots, `llms.txt`

See [CLAUDE.md](./CLAUDE.md) for the full architecture.

```bash
npm install
npm run dev
npm run build
```
